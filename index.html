Store team accounts in a free online database so you and your team can sign in from any device. How to set it up (2 min) ›
  1. Open console.firebase.google.com → Add project (free, no card).
  2. Build → Realtime Database → Create Database → start in locked mode.
  3. Open the Rules tab, paste this and Publish:
    { "rules": { "be_accounts": { ".read": true, ".write": false } } }
  4. Copy your database URL (looks like https://yourproject-default-rtdb.firebaseio.com) into the URL box above.
  5. Project settings (gear) → Service accounts → Database secrets → copy the secret into the secret box (it stays only on your device — used to save accounts).
  6. Click Save & Connect. Then make every device use it by baking this line into index.html on GitHub & redeploying (one time):
    var CLOUD_DB_URL = '';
